# 【比較】JavaとJavaScriptの違い

プログラミング初学者が最も混同しやすい言語、「Java」と「JavaScript」。名前は似ていますが、その出自、目的、動作環境、言語仕様は全く異なります。「インドとインドネシア」や「メロンとメロンパン」ほど違うと言っても過言ではありません。このドキュメントでは、両者の違いを明確に解説します。

## 概要

Java と JavaScript は、**名前が似ているだけで技術的な親子関係はほぼない別系統の言語**です。MDN も「JavaScript を Java と混同しないこと。JavaScript は『インタプリタ版の Java』ではない」と明記しています。Java は Sun Microsystems（現 Oracle）が1995年に発表したクラスベースのオブジェクト指向言語で、JVM 上で動かすことを前提に「Write Once, Run Anywhere」を掲げます。JavaScript は同じ1995年に Netscape の Brendan Eich が約10日で試作（当初は Mocha → LiveScript → JavaScript）した、プロトタイプベースの軽量言語で、当初は Web ブラウザに動きをつけるためのものでした。

一言で言うと、**Javaは「大規模で堅牢なシステムを構築するための重量級言語」** であり、**JavaScriptは「Webページに動きをつけることから始まった、軽量で柔軟な言語」** です。

## 詳細比較

| 項目 | Java | JavaScript |
| --- | --- | --- |
| **分類** | クラスベースのオブジェクト指向プログラミング言語 | プロトタイプベースのスクリプト言語（マルチパラダイム） |
| **主な用途** | サーバーサイド、業務システム、Androidアプリ | Webフロントエンド（ブラウザ）、サーバーサイド（Node.js） |
| **実行方法** | バイトコード（`.class`）に**コンパイル**してから JVM 上で実行 | エンジンが**インタプリタ／JIT コンパイル**して実行（事前コンパイル不要） |
| **実行環境** | Java仮想マシン (JVM) | Webブラウザ、Node.jsなど |
| **型付け** | 強い静的型付け (Strongly & Statically Typed) | 動的型付け (Dynamically Typed) |
| **開発元** | Sun Microsystems (現 Oracle) | Netscape (Brendan Eich) |

### 1. Java

Javaは、Sun Microsystemsによって1995年に発表された、クラスベースの厳格なオブジェクト指向プログラミング言語です。Java言語仕様（JLS）は Java を「汎用・並行・クラスベース・オブジェクト指向」「強く静的に型付けされる」言語と定義しています。「Write Once, Run Anywhere（一度書けば、どこでも動く）」という思想の通り、Java仮想マシン（JVM）が動作する環境であれば、OSに依存せずに同じプログラムを実行できます。

#### 主な特徴

- **コンパイル言語**: プログラムを実行する前に、ソースコード（`.java`）を機種非依存の「バイトコード」（`.class`）にコンパイル（変換）します。JLS は「コンパイル時に検出できる（し、しなければならない）エラー」と「実行時に起きるエラー」を明確に区別しており、実行前に多くのエラーを発見できます。
- **強い静的型付け**: 変数を使用する前に、その型（整数、文字列など）を明確に宣言する必要があります。これにより、コードの堅牢性や可読性が高まります。
- **プラットフォーム非依存**: バイトコードを各環境の JVM が解釈・実行し OS 間の差異を吸収するため、Windows、macOS、Linuxなど、様々な環境で同じアプリケーションを動作させることが可能です。
- **豊富なエコシステム**: 長い歴史の中で、Spring Frameworkなど、大規模なエンタープライズシステム開発を支える強力なライブラリやフレームワークが多数存在します。
- **主な用途**:
    - 大規模なWebアプリケーションのサーバーサイド
    - 企業の基幹システム
    - Androidアプリケーション
    - ビッグデータ処理

**Javaは、信頼性、安全性、移植性が求められる大規模システムの開発に適しています。**

### 2. JavaScript

JavaScriptは、1995年にNetscapeのBrendan Eichによって、当初はWebブラウザに動的な機能を追加するために開発されたスクリプト言語です。HTML/CSSと並び、Webフロントエンド開発に必須の技術となっています。

#### 主な特徴

- **コンパイル不要で実行**: ソースコード（`.js`）はエンジンが解釈して実行します。MDN は JavaScript を「軽量なインタプリタ型（または JIT コンパイル型）言語」と説明しており、開発者が事前にコンパイルする工程は不要です（現代のエンジンは内部的に JIT コンパイルを行います）。手軽に書き始めてすぐに動作を確認できます。
- **動的型付け**: 変数の型を事前に宣言する必要がなく、実行時に自動的に決まります。柔軟で書きやすい反面、予期せぬエラーの原因にもなり得ます。
- **ブラウザで動作**: WebブラウザにJavaScriptエンジンが内蔵されており、特別な環境構築なしでWebページにインタラクティブな機能を追加できます。
- **サーバーサイドでの実行**: Node.jsの登場により、サーバーサイドでも動作するようになり、WebアプリケーションをJavaScriptだけで開発することも可能になりました（MEAN/MERNスタックなど）。
- **豊富なライブラリ/フレームワーク**: React, Angular, Vue.jsなど、モダンなUIを構築するための強力なフロントエンドライブラリ／フレームワークが世界中で活発に開発されています。
- **主な用途**:
    - WebページのDOM操作（アニメーション、フォーム検証など）
    - 非同期通信 (Ajax) を利用した動的なコンテンツ更新
    - シングルページアプリケーション (SPA) の構築
    - Webサーバーの構築 (Node.js)

**JavaScriptは、Web開発を中心に、スピード感と柔軟性が求められる開発に適しています。**

## よくある誤解

- **誤解1：「JavaScript は Java の簡易版／方言」** — 誤りです。MDN は「JavaScript を Java と混同しないこと。JavaScript は『インタプリタ版の Java』ではない。両言語は構文・意味論・用途が大きく異なる」と明記しています。両者に直接の技術的親子関係はありません。
- **誤解2：「名前が似ているのは偶然」** — 偶然ではなく**意図的なマーケティング**です。当時 Java が急速に人気を集めていたため、Netscape は Sun Microsystems との提携発表に合わせて LiveScript を「JavaScript」と改名しました。Brendan Eich 自身がこの命名を「マーケティング上の方便」と振り返っています。技術的関連はないが、名付けは無関係でもない、という点が正確です。
- **誤解3：「JavaScript は一行ずつ解釈するだけの遅い言語」** — 古い理解です。MDN は JavaScript を「インタプリタ型**または JIT（実行時）コンパイル型**」と説明しており、V8 など現代のエンジンはホットなコードを機械語に JIT コンパイルして高速化します。「インタプリタだから常に遅い」という単純化は当てはまりません。
- **誤解4：「Java はコンパイル言語だからネイティブ機械語になる」** — 正確には Java は機種非依存の**バイトコード**にコンパイルされ、それを JVM が解釈・実行（多くは JIT で機械語化）します。最初から特定 CPU 向けネイティブバイナリになるわけではない点が、移植性（Write Once, Run Anywhere）の鍵です。

## 実務での選び分け

- **企業の基幹・業務システム、Androidアプリ、堅牢性が最優先の大規模開発** → **Java**。強い静的型付けとコンパイル時チェック、成熟したエンタープライズエコシステム（Spring 等）が活きる。
- **Webサイト／Webアプリのフロントエンド、ブラウザ上の挙動** → **JavaScript**（必要に応じて TypeScript を併用）。ブラウザで動く言語は実質 JavaScript 一択。
- **小〜中規模のサーバーサイドを素早く立ち上げたい・フロントと言語を統一したい** → **JavaScript（Node.js）**。学習・反復のスピードを取りやすい。
- **判断軸**：①動作環境（ブラウザ＝JavaScript、JVM 上の堅牢システム＝Java） ②型の厳格さをどこまで求めるか ③チームの既存スキルとエコシステム。両者は競合ではなく用途が異なるため、「どちらが優れているか」ではなく「何を作るか」で選ぶ。

## ひとことまとめ

Java と JavaScript は名前が似ているだけの別言語で、Java は JVM 上で動く強い静的型付けのコンパイル言語、JavaScript はブラウザ／Node.js で動くプロトタイプベースの動的言語です。作りたいものの動作環境で選び分けます。
